# 🎨 设计规范文档

> 个人博客系统 - 莫兰迪治愈主题 (浅色模式)

---

## 一、设计理念

| 关键词 | 说明 |
|--------|------|
| 温和 | 莫兰迪低饱和色彩营造治愈感 |
| 通透 | 玻璃拟态带来轻盈层次感 |
| 呼吸 | 留白适度，宛如纸质阅读体验 |
| 精致 | 细节打磨，提升整体质感 |

## 三、字体规范

### 字体组合

```
┌─────────────────────────────────────────────────────────────┐
│  Typography                                                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  标题字体    Playfair Display    优雅衬线体，用于大标题      │

│  代码字体    JetBrains Mono      现代等宽体，用于代码块      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 字体加载

使用国内镜像加速加载：
```html
<link href="https://fonts.loli.net/css2?family=Playfair+Display:ital,wght@0,400;0,600;0,700;0,800;1,400&family=Source+Sans+3:wght@300;400;500;600;700&display=swap" rel="stylesheet">
```

## 四、CSS 变量汇总

```css
:root {
  /* 主色 - 莫兰迪豆沙绿与干枯玫瑰 */
  --color-primary: #96A48B;
  --color-primary-light: #B5C4B1;
  --color-primary-dark: #7B8B6F;
  --color-accent: #D4B0B5;
  --color-accent-light: #E2C4C6;
  
  /* 背景 - 温暖的燕麦色/米灰色 */
  --bg-primary: #FCFBF9;
  --bg-secondary: #F0EBE5;
  --bg-tertiary: #E0E5DF;
  --bg-card: rgba(255, 252, 248, 0.8);
  --bg-card-hover: rgba(255, 255, 255, 0.95);
  --bg-glass: rgba(255, 252, 248, 0.65);
  --bg-glass-hover: rgba(255, 255, 255, 0.85);
  
  /* 文字 - 深咖/茶褐色调 */
  --text-primary: #3D4035;
  --text-secondary: #5C6055;
  --text-muted: #8D948D;
  --text-disabled: #B2BEB5;
  
  /* 边框 */
  --border-default: rgba(150, 164, 138, 0.15);
  --border-hover: rgba(150, 164, 138, 0.3);
  --border-active: rgba(150, 164, 138, 0.6);

  /* 功能色 */
  --color-success: #A9BA9D;
  --color-warning: #D8C06A;
  --color-danger: #C49799;
  --color-info: #98A9BD;
}
```
