# v1.2.0 Release Notes

> 覆盖范围：v1.0.2 → v1.2.0（含 v1.1.0 全部改动）
>
> 兼容性：数据库无结构变更，可直接升级；认证方式变更（httpOnly cookie）部署时需 HTTPS。

## 亮点

- 认证全面重构为 httpOnly cookie，前端不再接触 token，XSS 无法窃取登录态
- 多轮安全加固：生产密钥强度强制、上传魔数双重校验、查询参数全量验证、错误信息脱敏
- 移动端体验大改：触控反馈、底部弹出式模态框、后台表格列裁剪、滚动位置记忆
- 三阶段代码优化：审计清理、组件复用（Pagination / EmptyState）、动画规范统一

## 认证与安全

- 认证重构：JWT token 经 httpOnly + SameSite=Lax cookie 下发，新增登出接口，彻底移除 localStorage
- 生产环境强制 JWT_SECRET ≥ 32 字符，弱密钥拒绝启动
- 上传安全：webp 魔数双重校验（RIFF + WEBP）、扩展名由服务端按 MIME 决定、文件句柄泄漏修复
- 查询参数全量验证（status/category/tag/keyword），修复公开接口可被非法参数触发 500
- 500 错误生产环境统一脱敏，外键冲突正确映射为 400
- API 响应加 no-store，防止列表/搜索数据被浏览器或代理缓存

## 功能修复

- 浏览量防刷失效修复（时间格式统一）
- 草稿文章无法编辑修复（新增后台单篇接口 `/api/posts/admin/:id`）
- 分类更新别名可选语义、`is_top` 字符串误判
- 文章必须归属分类（移除「无分类」选项，历史无分类文章编辑时自动归入默认分类）
- 新发布文章自动置顶列表（sort_order 取最大值 +1），不再沉底
- Icon 生产构建失效修复（改用 import.meta.glob 静态打包）
- Toast 图标缺失补全、PostCard 移除 v-html（改用安全的高亮片段渲染）
- 搜索竞态、401 跳转丢失 redirect、分页页码 URL 同步

## 移动端体验

- 滚动位置记忆：列表 → 详情 → 返回精确恢复（含分页）
- 移动端菜单：交错滑入动画、滚动双锁（html + body）、修复 backdrop-filter 导致的菜单塌陷
- 触控反馈：按钮/卡片/链接按下反馈，触控目标 ≥ 40px
- 分类模态框改为底部弹出式，后台表格移动端裁剪次要列
- 安全区适配（刘海屏）、prefers-reduced-motion 全面支持

## 代码质量（三阶段优化）

- 代码审计：全量扫描清理，删除与全局重复的样式与死代码
- 组件复用：新增通用 `Pagination`、`EmptyState` 组件；状态标签、页面头部样式全局化
- 动画规范：统计数字计数滚动（useCountUp）、导航下划线滑动动画、AOS 时长对齐 200-500ms（ease-out）

## 部署

- 新增 `TRUST_PROXY` 配置（Nginx 反代时正确识别客户端 IP）
- 配置路径基于 `__dirname` 解析，不再受启动目录影响
- 宝塔 Nginx 配置文档（/uploads 静态伺服、/sitemap.xml 反代）

## 测试

- 新增滚动恢复单元测试，前后端共 42 个用例全部通过
- ESLint（含自定义安全规则）与 Prettier 全量通过

## 其他

- 开源协议切换为 Apache 2.0
- 页脚备案号与版权域名更新为最新
- robots.txt Sitemap 地址修正
