# v1.2.1 Release Notes

> 覆盖范围：v1.2.0 → v1.2.1（bug 修复与部署修复版本）
>
> 兼容性：数据库无结构变更，可直接升级。

## 修复：界面与交互

- 修复导航选中状态：改用精确匹配（`router-link-exact-active`），进入分类页时首页不再同时高亮
- 修复编辑器保存空标题草稿被后端拒绝的问题（无提示）：保存草稿前校验标题并给出友好提示
- 修复后台删除末页最后一条文章后页码越界显示空列表：自动回退一页
- 修复 401 跳转丢失 URL 参数：登录后回跳保留完整路径（含 query）
- 修复「返回」按钮在无历史记录时无效（直接访问/新标签页打开）：自动兜底回首页/文章列表

## 修复：部署与环境

- 新增 `.gitattributes` 统一 LF 换行符，解决 Windows 下 git 自动转 CRLF 导致的格式问题（开发环境）
- 修复 sitemap.xml 生成 `http://` 链接的问题：Nginx 反代需配置 `X-Forwarded-Proto $scheme`（见 README 部署章节）
- 服务器启动错误处理：端口被占用时输出友好提示并正常退出，不再无提示崩溃

## 更新：站点信息

- 页脚备案号更新：蜀ICP备2025145207号-2、川公网安备51180202512082号
- 页脚版权域名更新为 crq.homes
- robots.txt 的 Sitemap 地址修正为 https://crq.homes/sitemap.xml
