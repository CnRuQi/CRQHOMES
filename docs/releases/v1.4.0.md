# v1.4.0 Release Notes

> 覆盖范围：v1.3.3 → v1.4.0（对应提交 `1b60ade`）
>
> 兼容性：**数据库有结构变更**（users 表新增 `token_version` 列）——覆盖 `server/` 后重启 Node 即自动完成迁移，无需手动执行 SQL；无新增依赖，无需 `npm install`；服务器上的 `.env`、`data/`、`uploads/` 均不受影响。

本版本为两轮全量代码审查（2026-08-29 / 2026-08-31，全文见 `docs/code-review-2026-08-29.md` 与 `docs/code-review-2026-08-31-round2.md`）的集中修复批次，覆盖 server 与 client 全部源码，共落地 29 项：1 项严重、12 项中等、9 项建议、一致性专项 4 条，另新增 6 项测试并扩充打包文档。

## 功能修复：两处直接影响用户可感知正确性的问题

- **更新文章接口不再静默发布草稿**（严重）：`PUT /api/posts/:id` 省略 `status` 是验证器允许的合法请求，旧代码却把它解释为「发布」——一篇草稿会被不可逆地转为公开并写入发布时间。现改为保留文章原状态，与分类、个人资料接口的「半更新语义」对齐；空内容校验同步改用生效后的状态，草稿省略 `status` 时仍允许空正文
- **会话过期不再被误报为「连不上服务器」**：v1.3.3 引入的 401 分流实际读取 `error.response.status`，而拦截器抛出的是 `{code, message}` 普通对象，该判断从未生效——真实会话过期时登录页显示「无法连接服务器」，用户会反复刷新而不是重新登录。现改读 `error.code`，这条 v1.3.3 的失效修复在本版本真正落地

## 后端修复

- **改密后旧登录态失效**（安全增强）：users 表新增 `token_version`，JWT 携带签发时的版本号，落后即拒绝；改密后其他设备的旧 token 立即失效，当前浏览器自动重签 cookie 保持登录。伪造更高版本号同样被拒（只认完全匹配）
- **登录防用户名枚举**：用户不存在时也执行一次 bcrypt 比对（预计算哑哈希），「用户不存在」与「密码错误」的响应耗时一致，无法通过时间差探测账号
- **发布时间全面收口**：服务端新增 `published_at` 的 ISO 8601 校验，落库统一为 UTC 串（此前编辑器提交的本地时间串会入库并被当 UTC 解析，排序/sitemap 在中国时区偏移最多 8 小时）；转草稿不再清空发布时间（此前转草稿会丢原发布时间且无法恢复）；列表与归档排序统一 `COALESCE(published_at, created_at)` 兜底并收敛为同一常量，归档增加 500 条上限
- **数据库连接加 `busy_timeout`**：服务运行期间执行 `create-admin` 等写操作不再直接 500
- **`db:import` 安全护栏**：生产环境直接拒绝；非交互终端拒绝（不挂起）；交互环境要求输入站点名确认；自动化可显式 `IMPORT_FORCE=1`。此前该命令会无确认清空全站文章且不可恢复。导入数据现支持并强制写入 UTC 发布时间（此前全部等于导入时刻，归档挤进同一月份），并清理防刷孤儿记录
- **`create-admin` 三项健壮性**：校验失败改 `throw`，不再用 `process.exit` 跳过 finally（数据库连接与 readline 能正常关闭）；密码不回显依赖的 readline 私有 API 缺失时降级为正常回显而非崩溃；密码增加 72 字节上限（bcrypt 截断阈值，按 UTF-8 字节数）
- **浏览量计数与防刷记录纳入同一事务**：消除「计数已加、防刷没记」导致的重复计数
- **验证规则与查询去重**：create/update 共用同一份字段规则（防「新建校验了、编辑没校验」）；`searchPosts` 复用列表查询构造（顺带补上 `updated_at` 时间归一化）
- **`getPost` 预编译语句缓存**：按连接实例用 WeakMap 缓存，消除每次请求重复解析 SQL

## 前端修复

- **分类删除改读结构化字段**：后端错误响应新增 `data` 携带 `postCount`，前端拦截器同步透传，`Categories.vue` 优先读字段判断、保留旧版文案正则仅作降级——不再把后端中文文案当接口契约
- **`marked` 配置抽离**：从组件 setup 移到独立模块 `assets/js/markdown.js`。此前每次进入文章详情页都向全局 marked 注册一遍扩展，扩展栈随访问次数单调增长（缓慢内存泄漏）
- **文章详情页首帧不再闪「文章不存在」**：`loading` 初值修正
- **模态框滚动锁**：分类弹窗打开时锁定背景滚动、关闭或卸载时释放；滚动锁逻辑统一抽取到 `utils.js`，Navbar 与后台 Layout 改为复用（消除三份重复实现）
- **`useCountUp` 响应系统设置**：运行期间修改「减少动态效果」立即生效（此前只在页面加载时读取一次快照），切到「减少」时数字直接落到终值，切回时重新动画

## 无障碍

- 本批次无专门无障碍改动（v1.3.3 已补齐主要属性）

## 评估后不修

- **公开接口限流**：搜索为全表 LIKE 扫描，个人博客体量下成本可控，评估后不做；文章量上千时可引入 SQLite FTS5
- **首轮轻微项 L1 / L2 / L3 / L4 / L7 / L9**：`fs.readSync` 短读（低概率且失败方向为拒绝而非放行）、`UPLOAD_DIR` 越界提示（当前配置不触发）、`initDb` 导入期副作用（仅影响测试形态）、`validate` 用 `throw`（Express 可捕获，纯风格）、NAT 共享浏览量（防刷与统计准确的固有取舍）、`prefersReducedMotion` 已在一致性专项顺手解决
- **CSS 逐行审查与 `eslint-rules` 细节实现**未纳入本轮审查范围

## 覆盖升级与行为变更提醒

- **部署四步**（本次有 schema 变更，备份数据库为必做步骤）：

  ```bash
  cp -r data data.bak            # 1. 备份数据库
  tar -xzf server.tar.gz         # 2. 覆盖 server/
  pm2 restart blog-server        # 3. 重启 → 日志应出现「添加 users.token_version 字段...」
  tar -xzf dist.tar.gz           # 4. 覆盖 dist/，浏览器 Ctrl+F5
  ```

- **行为变更 1**：修改密码后，其他设备上的旧登录态立即失效（当前浏览器自动重签 cookie，不受影响）
- **行为变更 2**：`db:import` 增加确认环节——生产环境直接拒绝、非交互终端拒绝（自动化可用 `IMPORT_FORCE=1` 跳过，需自行确保已备份）、交互终端需输入站点名
- **行为变更 3**：转草稿不再清空发布时间，重新发布恢复原发布时间（此前会被重置为当前时间）
- 本版产物基线：`server.tar.gz` 74.6 KB / `dist.tar.gz` 909 KB（v1.3.3 为 69 KB / 910 KB）
- `docs/tasks/packaging.md` 新增「文件级最小增量升级（可选）」章节：后端可按改动清单打小包，前端不存在文件级增量
