# v2.0.1 Release Notes

> 发布日期：2026-09-29
>
> 覆盖范围：v2.0.0 → v2.0.1
>
> 本版本修复后续安全审查和前端流程回归发现的问题。GitHub Release 附件为 `server.tar.gz` 与 `dist.tar.gz`。

## 安全修复

- Cookie 写接口校验 `Origin`/`Referer` 或同源 Fetch Metadata；来源白名单来自 `CORS_ORIGIN`、`SITE_URL` 和可选的 `CSRF_TRUSTED_ORIGINS`。
- 登录与改密密码统一限制为最多 72 个 UTF-8 字节，在 bcrypt 前拒绝超长输入。
- 公开文章详情增加 IP 限流；`view_tracking` 有 100,000 行容量上限，超限时淘汰最早记录。旧数据库初始化会回填容量计数，插入和删除触发器持续维护计数。
- 图片上传限制文件、字段、部件、字段名、字段值和 multipart header 数量。
- 登录、搜索和文章详情等限流器支持 `RATE_LIMIT_STORE_MODULE` 接入共享 store。未配置时使用进程内存 store，并在启动时提示此配置仅适用于单实例部署。
- 登录失败账号计数改为用户名与客户端 IP 组合，避免仅凭用户名锁住所有管理员会话。
- `.gitignore` 覆盖 `.env.*`，保留安全模板 `.env.example`。

## 前端与运行环境

- 修复搜索输入清空、重复查询参数和请求失败时的旧结果状态。
- 保存文章期间阻止普通导航覆盖保存流程；排序并发操作排队提交最新顺序。
- 分类弹窗增加提交保护、焦点进入与循环、关闭后的焦点恢复；请求失败状态与空列表分开显示。
- 768px 移动断点与 769px 桌面断点互斥，修复全局玻璃样式在 768px 形成 fixed 子元素包含块的问题。
- 项目最低 Node 版本统一为 20，`server/package.json` 增加 `engines.node` 声明。
- GitHub Actions 对 root、server、client 分别执行联网 `npm audit --audit-level=high`；high/critical 漏洞或 registry 不可达都会阻断 CI。

## 部署与迁移

后端启动时会幂等创建 `view_tracking_stats` 和计数触发器，并从旧 `view_tracking` 数据回填当前记录数。升级前仍建议备份数据库、环境文件和上传目录。打包脚本保留 `server/.env.example`，排除所有真实 `.env` 与 `.env.*` 配置。

多实例部署需要设置 `RATE_LIMIT_STORE_MODULE`，并提供导出 `createStore(name)` 的共享存储模块。生产环境需配置有效的 `CORS_ORIGIN` 和 `SITE_URL`；额外管理来源通过 `CSRF_TRUSTED_ORIGINS` 显式列出。
