# v2.1.0 Release Notes

> 发布日期：2026-10-02
>
> 覆盖范围：v2.0.1 → v2.1.0
>
> 对应提交：`06a031e`
>
> 本版本以前台「获奖级」设计迭代为主线，修复三个系统性 CSS 缺陷（全站按钮着色失效、文章页标题永久隐藏、封面加载态布局跳动），并按量化标准补齐无障碍触控目标。GitHub Release 附件为 `server.tar.gz` 与 `dist.tar.gz`。

## 功能修复

- 全站按钮着色失效：`reset.css` 的元素选择器（`button { background: none }`）以更高特异性压过 `:where(.btn-primary)` 的零特异性着色规则，导致所有 primary/secondary/danger/ghost 按钮背景透明、文字继承墨色。修复方式为将 `reset.css` 整体纳入 `@layer reset`（仅 `.sr-only` 与 `.skip-link` 两个全局工具类保留在 layer 外）——分层规则永远低于未分层规则，「reset 让位组件」从此由层级行为保证，不再依赖特异性博弈。
- 文章页标题永久隐藏：`data-reveal="mask"` 的初始态 `clip-path: inset(0 0 102% 0)` 将可见区域裁剪为零，而 IntersectionObserver 的交集计算会应用 clip-path，intersectionRatio 恒为 0，阈值 0.06 永不满足，`is-revealed` 永不添加。修复为 mask 初始态保留 2px 墨线（`inset(0 0 calc(100% - 2px) 0)`），并将揭示阈值调整为 0（触发时机由 `rootMargin` 的负值提前量负责）。
- 封面加载态布局跳动：外链封面 pending 期间卡片露出死灰底、文章页封面塌陷为一条白边。文章卡片封面改为三态（渐变纸底 + 居中墨点 → onload 淡入 → error 降级占位）；文章页封面增加 `min-height` 与同款纸面渐变；缓存命中的图片在挂载后补一次完成态校对，避免停在透明态。
- SVG 图标消失：`Icon.vue` 的行内样式表达式存在引号嵌套截断（`Unterminated template`），样式对象移入 script `computed` 后恢复正常。

## 后端修复

- 无（`server/` 相对 v2.0.1 零改动；本版本全部变更位于前端与文档）。

## 前端修复

- 移除 Hero 朱印（设计决策）。
- 搜索框双层描边：焦点指示改由外层容器的 `:focus-within` 承担（苔绿边 + 光晕），input 自身不再叠加 focus-visible outline；焦点可见性不丢失，仅更换载体。
- 封面加载失败占位（image-fallback）由纯白底改为纸面渐变，与无封面占位统一视觉语言。
- Hero 墨晕被不透明祖先背景遮挡（`isolation: isolate`）；磁性交互在滚动后吸引点偏移（`pointerenter` 重测 rect）；落雪在 144Hz 高刷屏上倍速（改为时间驱动，dt 归一并设上限）；页脚链接组窄屏溢出（`flex-wrap`）。
- 路由过渡改为不对称节奏（离开 150ms ease-in 上飘、进入 420ms emphasis 落定）。
- 新增前台体验层：全站落雪画布（仅 pointer:fine 且非 reduced-motion；标签页隐藏暂停；随主题切换雪色）、墨点光标跟随、`v-magnetic` 磁性交互、主题切换圆形墨晕扩散（View Transitions API，渐进增强）、Hero 逐字揭幕与页脚落款宣告区。
- `docs/design.md` 重写为「当前代码真实生效的设计系统」，以 `variables.css` 为唯一事实来源；新增 `docs/audits/design-audit-2026-10-01.md` 设计八维度审计记录。

## 无障碍

- 触控目标补足 44×44px 标准（8 处）：桌面导航链接与管理入口（垂直 padding 12px）、logo 与页脚导航/备案小链接（透明热区伪元素，视觉不动）、Hero「浏览文章」CTA 与跳转链接（垂直 padding 12px）。
- 正文（`.prose`）行高由 1.88 调整为 1.72（`--leading-relaxed`），回到 1.5–1.75 可读区间并与全站正文同档。
- 对比度按 WCAG AA 量化复核：亮/暗两主题 23 组文本/背景组合全部 ≥4.5:1（含按钮文字、状态标签与禁用文字）。

## 评估后不修

- Markdown 编辑器 chunk 约 882 kB 的构建警告：既有现象，编辑器为后台独立路由按需加载，不影响前台首屏。
- 外链封面图床（img.cnruqi.site）在本机网络不可达：环境问题，非代码缺陷；`@error` 降级占位已兜底。
- 移动菜单展开态菜单项渲染宽度 43.97px（目标 44px，差 0.03px 属亚像素舍入）：不再追。

## 覆盖升级

```bash
cp -r data data.bak                 # 1. 先备份数据库
tar -xzf server.tar.gz              # 2. 解压覆盖 server/
pm2 restart blog-server             #    （宝塔：面板重启 Node 项目）
tar -xzf dist.tar.gz                # 3. 解压覆盖站点 dist/
```

- 前端覆盖后要求用户 **Ctrl+F5** 强制刷新一次，否则会命中旧的带 hash 资源。
- 本版本后端零改动，无需在服务器执行 `npm install`，无 schema 迁移。
- 产物校验参考：`dist.tar.gz` 923,573 B / `server.tar.gz` 87,409 B，条目结构与 v2.0.1 产物一致。

**行为变更提醒**：

- `reset.css` 全文移入 `@layer reset`：任何未分层样式（组件、主题、第三方注入 CSS）从此自动压过 reset。若线上曾有依赖「reset 压过组件」的样式补丁，需复查。
- 正文行高 1.88 → 1.72：长文段落纵向密度略增，属预期视觉变化。
- 触控热区扩大：页脚备案行内相邻链接的热区存在少量重叠，重叠区域命中任一链接均无副作用。
- 文章页标题入场由「整块上移淡入」变为「2px 墨线自上而下晕开」；封面图片加载完成后约 420ms 淡入，弱网下不再出现灰色占位闪现。
