# 代码优化与安全增强

> 时间：2026-05-10 11:24

## 本次主要修改

1. 创建 Toast 组件替代 alert 提示
2. 创建 useToast composable 全局状态
3. 更新 Editor.vue 替换所有 alert
4. 更新 Categories.vue 替换所有 alert
5. 添加登录速率限制 (15分钟5次)
6. 添加密码修改速率限制 (1小时3次)

## 详细说明

### 1. Toast 提示系统
- 新增 `client/src/components/Toast.vue`
- 新增 `client/src/composables/useToast.js`
- 更新 `client/src/App.vue` 集成 Toast

### 2. 速率限制
- 登录：15分钟内最多5次
- 密码修改：1小时内最多3次

### 3. httpOnly Cookie
- 登录成功后设置 httpOnly cookie
- 生产环境启用 secure 标志
- sameSite: strict 防止 CSRF

### 4. 响应式模糊
- 移动端 (<768px)：纯半透明背景，无模糊
- 桌面端 (≥768px)：启用 backdrop-filter blur
