# 代码审查修复 - 安全与验证增强

> 时间：2026-05-10 12:00

## 本次修改内容

1. MarkdownEditor 禁用 HTML 预览防 XSS
2. upload.js 删除无用导入，使用 crypto.randomUUID()
3. upload.js 对 originalname 做 path.basename() 清洗防路径穿越
4. app.js 为 uploads 静态资源添加 X-Content-Type-Options: nosniff
5. validator.js 新增 sortOrder 验证规则
6. post.js 路由加入 sortOrder 验证中间件
7. categoryController.js 删除分类前检查关联文章数量
8. validator.js avatar 验证改为相对路径校验
9. auth.js store 移除 localStorage 读写，依赖 httpOnly cookie
10. postController.js 浏览量增加 IP 去重防刷（Map + 5分钟 TTL）

## 详细说明

### 1. XSS 防护
- `MarkdownEditor.vue` 的 `:htmlPreview` 从 `true` 改为 `false`
- 防止 Markdown 中的恶意 HTML 脚本执行

### 2. 文件上传安全
- 删除 `const { v4: uuidv4 } = require('crypto')`（crypto 无 v4 导出）
- 改用 `const crypto = require('crypto')` + `crypto.randomUUID().slice(0, 8)` 生成文件名
- 文件名生成时用 `path.basename(file.originalname)` 清洗，防止路径穿越

### 3. 静态资源安全 Headers
- `/uploads` 路由添加 `X-Content-Type-Options: nosniff`
- 防止浏览器 MIME 类型嗅探攻击

### 4. 输入验证补全
- `updateSortOrder` 新增验证：posts 必须为非空数组，id 为正整数，sort_order 为整数
- avatar 验证从 `isURL()` 改为仅允许 `/` 或 `./` 开头的相对路径

### 5. 分类删除保护
- 删除分类前查询关联文章数量
- 若有文章关联则拒绝删除，返回错误提示

### 6. Token 存储优化
- 移除 `localStorage.setItem('token')` 和 `localStorage.removeItem('token')`
- 完全依赖后端 httpOnly cookie 认证

### 7. 浏览量防刷
- 使用 `Map` 存储 `IP:文章ID` 键，5 分钟 TTL
- 每分钟清理过期记录
- 同 IP 同文章 5 分钟内只计一次浏览
